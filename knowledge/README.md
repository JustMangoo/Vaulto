# Vaulto Knowledge Base

This folder is where I (Claude) keep durable, working knowledge about this
project as it develops, alongside the code itself, so it's version-controlled
and travels with the repo rather than living only in a chat history.

Files here:

- `stack.md` - chosen architecture and tech stack, with the reasoning behind
  each major decision (and what was tried/rejected before landing on it).
- `repo-notes.md` - practical gotchas about this specific repository
  (git history quirks, structure, things to watch for).

These get updated as the project moves forward. If something here goes
stale or turns out wrong, it should be corrected in place rather than left
to rot.
